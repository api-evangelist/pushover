Starting May 1, 2026, Pushover’s API sending limitations and capacity upgrades will become per-account rather than per-application. tl;dr Unless you are sending many thousands of notifications per month, this change will not affect you. Current limits Currently each user can register a capped number of applications and each application is given a free quota to send 10,000 messages per month before needing to be upgraded.
